SAMBA beamline control scripts based on ipython

SCOPE: 
1. unify the control of tango devices in a single script environment
2. manage the scan of a single motor in step by step and on the fly configuration
3. being maybe primitive, lacking features, but rock solid for production
4. lightweight and flexible enough for programming experiments on short notice
5. the playground is a xas beamline
